# Codex 用量统计

这是非官方社区插件。直接执行统计并返回报表；每位使用者仅使用自己的Codex登录和已有SSH连接。

## 执行

- 脚本位于本技能目录 ../../scripts/codex_daily_usage.py，需要Python3.8+，无第三方运行依赖。
- 默认 --all-sources --profile-reference，账户总量取Profile兼容接口，任务明细来自本机和Codex中已注册的SSH来源，日期为UTC。
- 最近N天使用 --days N；单日使用 --from-date YYYY-MM-DD --to-date YYYY-MM-DD，并设为同一天。UTC日期与本地自然日可能不同，回复中写明。
- 输出路径优先遵循当前工作区或用户给定的位置；否则在当前工作区创建outputs目录，明确传 --output outputs/codex-daily-usage.html。不要把报表写进插件安装目录。
- 脚本同时生成近7天.csv和每日.daily.csv；每日明细按token数从高到低排序。需要JSON时使用 --summary-output。
- 用户仅要SSH或本机明细时分别使用 --ssh-host <已有别名> 或 --local，可继续追加 --profile-reference 对照账户。明确只要日志或本地时区时省略账户参数，按需要使用 --utc-offset=+0800 等偏移。
- 自动发现读取当前用户的Codex连接配置，不硬编码主机、用户名、路径。只有现有配置不足或多主机无法确定目标时才询问。无法读服务器时标注失败，不用本机记录冒充SSH结果。

## 数据和说明

- 账户模式只向 https://chatgpt.com/backend-api/wham/profiles/me 发GET，使用本机现有ChatGPT登录。不索要密码、私钥或令牌；不输出、打包或上传认证文件。拒绝重定向，不访问其他人的账户。
- 这是客户端兼容接口，并非公开稳定的统计API，可能变化。接口缺少日期或失败时明确标注，不能按零处理或把日志总量冒充账户值。
- 日志来源账户身份只以摘要核对；一致后才计算账户占比与差额。服务器返回用量和名称元数据，不返回原始对话正文。
- 独立任务标识使用首条session_meta.payload.id，不能用共享session_id混淆主任务和后台审批。继承历史及重复用量事件去重。
- 使用真实项目名和任务名；无项目仅显示任务名；缺少标题时以首条请求前80字符回退。报表可能含任务名称和路径信息，属于使用者自己的数据。
- 任务当天/近7天占比以相应账户token总量为分母。后台审批与未归属差额单列，不把差额摊派到任务。token占比不等于订阅额度消耗比例。
- 模型调用图来自已收集日志，不能称为服务端完整调用次数。缓存输入单列，不额外叠加到账户总量。

最终给出报表链接、日期和时区、读取时间、账户显示值及可定位明细范围。接口值可更新，不写死历史数字。
